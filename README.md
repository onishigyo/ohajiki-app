# おはじき銀行 (ohajiki-app)

「時間通貨」として使っているおはじき（ガラス玉）の、**稼いだ記録**をつける
小さな iPad アプリ。子どもが「がんばること」をタップするとその場で「＋◯こ」と
もらえ、親は1日の終わりに「今日は何こ渡せばいいか」を自動集計で確認する。

個人プロジェクト。UI は日本語のみ。

## しくみ

我が家では、おはじきを子どものスクリーンタイムの「通貨」にしている：

- **おはじき1こ = 一定時間の画面時間**（動画・ゲームなど）
- 読書・お手伝い・早寝などの「がんばること」で、おはじきを **稼ぐ**
- 画面を見たいときは、貯めたおはじきを親に **渡して** 交換する

おはじきを実際に配る・受け取るのは手渡しのまま。これまで稼ぎを紙にメモして
いたのを置き換えて、**1日の終わりに渡す枚数が自動で出る**ようにしたのがこれ。

## 他のごほうび制でも

ポイント制のお小遣い、ごほうびシール、トークンエコノミー的な取り組みなら、
設定で「がんばること」の名前と枚数を変えれば流用できると思う。ただし画面の
文言もアプリ名も「おはじき」前提なので、そこは読み替えるつもりで。

## 使い方

- **子ども**: メニューをタップ → その場で確定してお祝い演出。承認待ちは無い
  （最終的におはじきを渡すのは親の判断なので事前承認は不要）
- **親**: 歯車 → 4桁 PIN → 「今日の集計」で内訳を見て、変な記録は 🗑 で消し、
  1日の終わりに「渡した」で締める。「設定」でがんばること・PIN・うさぎの気分を調整
- **翌日はじめて開いたとき**: うさぎのキャラクターが昨日の数を教えてくれる
  （数に応じて さみしい / ふつう / うれしい）。タップで通常画面へ

## 技術

単一 HTML アプリ（フレームワークなし・TypeScript + Vite）。
`vite-plugin-singlefile` でビルド結果を1つの HTML にまとめ、iPad の Safari で
「ホーム画面に追加」して使う。

| ファイル         | 責務                                                                                |
| ---------------- | ----------------------------------------------------------------------------------- |
| `src/types.ts`   | ドメイン型（`State` / `Rule` / `Entry`）だけ                                        |
| `src/logic.ts`   | 純粋ロジック（集計・正規化・判定・CRUD）。DOM も storage も触らない。テストの主対象 |
| `src/storage.ts` | 永続化の seam。現状 localStorage。読み込み時に必ず `normalizeState` を通す          |
| `src/main.ts`    | DOM 描画とイベント配線のみ                                                          |
| `src/style.css`  | 全スタイル                                                                          |
| `index.html`     | 静的シェル                                                                          |

詳しい原則は [CLAUDE.md](CLAUDE.md)。

## 開発

パッケージマネージャは pnpm。

```bash
pnpm install
pnpm dev           # Vite dev サーバ（http://localhost:5173）
pnpm test          # Vitest
pnpm lint          # ESLint
pnpm format        # Prettier
pnpm build         # 型チェック → 単一 HTML を dist/ へ
pnpm preview       # ビルド結果のプレビュー
```

## デプロイ

Cloudflare（Workers 静的アセット。`main` への push で自動、`dist/` を配信）。
手順は [docs/DEPLOY.md](docs/DEPLOY.md)。

## データとプライバシー

- サーバにデータを保存する処理は **無い**。記録はその端末のブラウザの
  `localStorage`（`ohajiki-state` キー）だけに入る。他端末とは同期しない
- 公開 URL にアクセスしても見えるのは「まだ誰も使っていない空の UI」
- 子どもの記録データ（書き出した JSON 等）はリポジトリにコミットしない。
  `.gitignore` で `*.ohajiki.json` を除外している
