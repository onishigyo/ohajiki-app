画面に出る言葉を1つずつ棚卸しして、ブレを潰し、あるべき文言に揃えるための基準。 実装（index.html / src/main.ts）と突き合わせて使う。

#48 で承認工程を廃止

子のタップで記録はその場で確定し、「＋◯こ もらった！」演出が出る。親側の 承認タブ・一括承認・却下は撤去（親タブは 今日の集計 / 設定の2つ）。不正・打ち間違いは今日の集計の 🗑で消す。子の かくにんまち ◯こ 見込み表示（#17）も撤去。 以下の「申請 / 承認 / 承認まち / 却下」まわりの記述は歴史的記録で、いま画面には出ない。生きているのは fixed/timed シート・PIN・今日の集計・締め・設定の文言と漢字ポリシー。

1 · 先に決めること

2026-08-28 に確定。下の表の「あるべき文言」はこの2つの決定を反映ずみ。

決定 A — 子ども画面の漢字 → 小4まで（v2・2026-08-28）

当初 A-1（小2まで）で実装 → 対象の子どもの読解に合わせて 小4までの教育漢字は使う（ふりがな無し）に引き上げ。 具体的には なにを→何を、 おねがい→お願い、 まえの→前の、 おしてね→押してね。 範囲外・かなの方が読みやすい語（がんばる／もらう／ おはじき／かくにん＝認は6年）はかな。分かち書きは維持。

決定 B — 親画面 → 通常どおり漢字（v2）

当初 B-1（かな寄り）→ 親画面はかな縛りをやめて通常の漢字。 けす／けってい→消す／決定、 とじる→閉じる、 もどす→戻す、 わたした→渡した、 よびかた→呼び方、 あんしょうばんごう→暗証番号。 トースト＝「〜しました」、見出し＝体言止め、絵文字なし は継続。

2 · 表記ルール

助数詞は数字にくっつける（スペースなし）

3 こ もらえるよ → 3こ もらえる。 45分 3回 も同じ。単語の区切りのスペースとは別扱い。

時間・回数は「分」「回」（決定 A-1）

子ども画面も含めて漢字に統一：15分で 2こ、 30分 → 4こ、2回、3回ぶん（45分）。 「◯回ぶん」の「ぶん」だけ、分（フン）と読みがぶつからないようかな。

単語の間のスペースは子ども画面だけ

今日 なにを がんばった？ のような分かち書きは早く読めるので継続。 親画面は詰める（今日の集計）。ルールを明文化するだけで、いま揃っている。

絵文字は「1メッセージに最大1つ・空状態のみ」

トーストは おねがいしたよ！ 🌟 と 却下しました（無し）が混在。 → 子どものトーストは末尾に1つまで、親のトースト・操作ボタンは絵文字なし、空状態（🫙 ✅）は可。

アプリ名

正式：おはじき銀行。見出しも同じ（装飾なし）。ホーム画面の短縮名（manifest short_name）おはじき はアイコン文脈なので可。
