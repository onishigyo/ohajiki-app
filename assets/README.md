# assets/

マスコット等の**元画像**を手元に置く場所。ここの画像は `.gitignore` 済みで
**リポジトリには入らない**（配信用に切り出したぶんだけ `public/` に置く）。

原本が必要になったら、この README のポーズ表を頼りに再度もらう／作り直す。

## character-sheet.png（git 管理外）

子どもが考えたマスコット（ピンクのうさぎ・星リボン・おなかにハート）。10ポーズの
コンタクトシート（2816×1536 / PNG / 5×2 グリッド・1セル ≒ 563×768px）。

うさぎのグリーティング（#51）で使う。境界は `State.mascot`（`sadMax` / `okMax`、
初期 4 / 9）で親が調整。昨日データ無し・0こ は「さみしい」。

| セル位置 | ポーズ                      | 切り出し先                            |
| -------- | --------------------------- | ------------------------------------- |
| 2段目2   | きらきら・両手あげ大喜び    | `public/mascot-happy.png`（うれしい） |
| 2段目5   | 手をあわせて笑顔            | `public/mascot-ok.png`（ふつう）      |
| 2段目3   | たれ耳・うるうる            | `public/mascot-sad.png`（さみしい）   |
| その他   | 立ち・杖／考え中／お茶 など | 予備（未使用）                        |

### 切り出し方

PIL 等が無い環境なので headless Chrome の canvas で切った（幅240px・各 ~150KB）。
セルをそのまま（余白/枠を軽くトリムするだけ）960→240 に縮小。背景の白〜淡ピンクの
グラデはそのまま活かし、表示側で角丸フレームに収める（`.greeting-img`）。
